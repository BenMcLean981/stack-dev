Added `stack migrate`, an upgrade path for workspaces generated by an older CLI.

It swaps ESLint for oxlint, Prettier for oxfmt, and tsup for tsdown; replaces the `eslint-config` and `prettier-config` packages with `oxlint-config` and `oxfmt-config`; points every dependency the catalog carries at `catalog:` (which is what moves a workspace onto TypeScript 7, including a `typescript` pinned in `peerDependencies`); refreshes the `catalog:` block; and teaches turbo the new `format` tasks.

Detection reads what is on disk rather than trusting a recorded version, so a hand-edited workspace migrates correctly and re-running the command is a no-op. `--dry-run` prints the plan without writing, and the command refuses to run against a dirty git tree unless given `--force`, so `git diff` is the review and `git checkout .` is the undo.

Workspace files are edited rather than regenerated — custom turbo tasks, extra `package.json` keys, and the `packages:` globs all survive. Source formatting and `vitest.config.ts` are deliberately left alone.
